# MeetNote R1 · 可挂佩 AI 助手设计细化

2026-09-29｜产品与交互研究版｜不可用于生产

定位已根据用户确认从“会议记录器”调整为“圆润、可挂佩的 AI 助手”，会议记录保留为核心模式。R0 原文件完整保留；R1 没有继承 R0 的 CAD 检查结论，也没有新增可投板文件。

- [产品、架构与制造基线](产品与工程基线.md)：场景、范围、实体操作、音频输出、接口、热设计、尺寸、成本、验证门槛。
- [交互与预算比较页](design-review.html)：可在浏览器打开；切换模式查看示意屏幕，比较尺寸目标，调整电池和负载计算续航。全部离线，无网络请求，不录音、不调用 AI。
- [参数](design_parameters.json)：所有研究假设的机器可读版本。
- [预算重算脚本](scripts/check_design.py)：Python 标准库即可运行。
- [本机计算记录](verification/design_checks.json)：算术与约束检查；不是物理验证。

本版实际完成：产品基线、交互原型、架构取舍、屏幕接口预算、续航与热敏感性计算、采购成本工作表、下一轮样机的验收条件。

本版尚未完成：新的 KiCad 布线、FreeCAD 装配与 PCB STEP 配合、Blender 工程外观、供应商正式报价、AI 服务接入及实物测试。页面里的外观图是二维设计意图，不能用作开模或证明无干涉。

重算：在本目录执行 `python3 scripts/check_design.py`。报告中的 FAIL/OPEN 是有意保留的工程风险，脚本正常退出只表示计算完成。
