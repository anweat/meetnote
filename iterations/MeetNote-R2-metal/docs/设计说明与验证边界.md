# R2 金属壳、贴合、GNSS与运动感知

日期：2026-09-29。级别：设计估算 + 本机CAD/脚本验证。实物测试：无。

## 结构选择

采用“6061铝前壳/中框 + 顶部非金属天线帽 + 非金属可拆后盖 + 局部周边贴合”。整机并非封闭全金属盒。铝件标称壁厚1.5mm、平面圆角R12，主体76×104×34mm；侧键及隐私拨杆最大宽约76.4mm，挂点总高108mm。顶部非金属区域从Y=72.2mm延伸到104mm。实际铝材、涂层厚度、倒角和工艺公差待工厂DFM。

R1的68×90×26mm只是研究目标。本次用现成计算/相机模组和2500mAh电池保守包络细化后，需要更大的空间；不能把76×104×34说成已满足R1小型化。玻璃、胶层、螺钉和天线均按各自空间建模，没有依靠Blender缩放掩盖干涉。

60个最终对象包括：铝壳、带双挂点RF帽、后盖、压缩密封圈、螺柱/螺钉、主板及支柱、计算模组、电池、屏幕及盖板/胶带、相机及盖板/支撑环/胶环、GNSS模组/地板/天线预留、FPGA、IMU、低功耗控制域、电量计、电源区、时钟/配置区、四麦/声学胶圈/膜、扬声器声腔、振动器、USB接口、FPC路径片、热桥/导热垫、侧键/拨杆、两条独立指示光导。

## 封胶与贴合分四类处理

1. **屏幕周边贴合**：0.7mm盖板，0.2mm周边胶层，有独立沉台。显示模组与盖板之间保留空间，不宣称OCA光学全贴合。单台用现成模组和可返修周边胶更可行；若做全贴合，应采购厂家贴合组件或单独报价，不能只把两层固体画在一起。
2. **镜头保护窗**：0.7mm窗口、0.2mm胶环和承托环。透过率、反射、胶挥发污染、热胀冷缩、镜头视场遮挡与对焦影响待光学验证。
3. **后盖密封**：标称0.40mm材料压到约0.30mm的候选压缩圈，螺钉可拆。压缩率和胶圈材质尚未选定；螺孔、USB、按键和天线帽接缝尚无连续密封，不能承诺IP等级。
4. **内部点胶**：后续仅在必要线束/连接点局部固定，不整腔灌封。不得把电池膨胀空间、麦克风声孔、透气/泄压路径、测试点和可更换接口灌死。胶与塑料/涂层/麦克风材料的相容性、固化条件和返修方式待验证。

封胶不自动降低成本，也不自动改善散热。导热胶、结构胶、密封胶和光学胶的作用不同，不能互换。第一台需要频繁调试，预留可打开后盖。3M的电子粘接资料也将粘接、密封与返修能力作为不同设计要求讨论。[3M返修与粘接](https://www.3m.com/3M/en_US/consumer-electronics-us/applications/electronics-bonding/design-challenges/)

## GNSS、蓝牙和IMU

|功能|候选/包络|接口与用途|未关闭项|
|---|---|---|---|
|Wi-Fi/蓝牙|Zero 2 W内置|Wi-Fi上传，BLE配网/状态|不重复增加蓝牙芯片；模组实际天线端位置、金属边缘距离和人体遮挡测试待做|
|GNSS|LC76G系列，10.1×9.7×2.4mm级|优先UART；可留PPS及复位；支持GPS等多星座|AB/PA/PB功耗与供电不同，后缀未冻结，不可混用原理图|
|GNSS天线|18×18×4mm仅为预留；24×24×1mm地板|置于顶部非金属窗口，远离高速时钟与升压区|没有具体天线型号或匹配数据；地板大小、朝向、馈线、LNA供电仍待设计|
|六轴IMU|BMI270，2.5×3.0×0.8mm、14-LGA|I²C/SPI＋中断；低功耗运动检测、取起亮屏、活动事件|安装轴向、应力隔离、FIFO读取、阈值和佩戴分类需标定|
|低功耗控制域|5×5mm占位＋外围|读取IMU中断、监测电量/温度、控制SoC电源|未选芯片；Linux关机恢复与文件系统安全需要实现|
|电量计/RTC/NTC|电量计占位，RTC可依控制域方案集成|估计剩余时间、维护时钟锚点、保护电池|不能盲目堆芯片；按最终平台已有能力去重|

资料：[Zero 2 W规格](https://www.raspberrypi.com/products/raspberry-pi-zero-2-w/)、[LC76G硬件设计V1.3](https://www.quectel.com/content/uploads/2023/05/Quectel_LC76G_Series_Hardware_Design_V1.3.pdf)、[BMI270原厂](https://www.bosch-sensortec.com/en/products/motion-sensors/imus/bmi270)。上述裸模组/芯片尺寸不能套给对应开发板；例如DFRobot BMI160台架板为22×27mm，不能替换R2中2.5×3mm的BMI270几何。[开发板资料](https://www.dfrobot.com.cn/goods-1693.html)

GNSS定位成功依赖天线与可见天空。胸前挂佩时天线方向不断变化，室内会议不应承诺可定位。超时返回无fix，保留上次位置的时间和精度，不能当成当前位置；可以在用户允许后使用手机位置来源，并明确来源不同。当前GNSS地板是天线有意需要的导体，不应套用“天线周围一律无金属”的粗略规则；外壳窗口、地平面和匹配必须按最终天线规格联合设计。

## 活动触发逻辑

活动记录作为单独开关。默认可在已启用时记录运动事件；运动中断只唤醒低功耗控制域或点亮屏幕，不自动打开麦克风/相机。需要自动采集的后续模式必须单独授权，并保持原有实体采集许可与状态灯。

建议起点（未标定）：加速度25Hz低功耗观察，陀螺仪平时关闭；检测运动持续约2s，进入活动候选；5s消抖，30s冷却抑制挂绳摆动反复唤醒。选定BMI270模式后需按数据手册合法ODR/特性配置实现，不能直接把这些产品阈值当寄存器值。手持取景/姿态调整时再打开陀螺仪。挂坠摆动不等于人在走路，不能把IMU供应商“支持计步”直接当胸前步数准确性证明。

若用户启用户外轨迹：运动开始后请求一次定位，fix后按可配置间隔更新；搜星超过约45–60s退避，防室内长时间耗电；该超时是产品策略，非保证冷启动时长。连续轨迹另设模式，保留精度、fix类型、UTC与单调时间、数据来源、无定位区间和取消/删除。

事件格式示意：`event_id, device_id, monotonic_ns, utc_anchor, motion_state, confidence_hint, location{source,lat,lon,accuracy_m,fix_age_s,valid}, consent_scope, trigger_reason`。位置与活动信息和录音一样进入加密存储，上传按用户选择；不要放进明文AAD。IMU事件只说明传感器观察，不能据此推断用户意图、自动形成会议决定。

## 功耗、射频与热

LC76G官方V1.3的连续跟踪典型值随版本差异显著：AB约108.57mW、PA约32.01mW、PB约28.08mW（原厂测试条件）。这些不包含我们自己的天线与稳压损耗，不能引用低功耗后缀数字给任意开发板。[原厂硬件设计，表3](https://www.quectel.com/content/uploads/2023/05/Quectel_LC76G_Series_Hardware_Design_V1.3.pdf)

整机预算暂给GNSS含天线/外围增加0.18W、IMU和常开控制域增加0.025W。叠加R1的2.6W为2.805W；沿用2500mAh、3.7V、0.8寿命、0.88效率、0.9保留系数，估算2.09h。GNSS间歇关闭会降低平均值，但搜星重试可能抵消收益。该结果无实测，峰值仍需电芯/供电验证。

铝中框有利于扩散芯片热量，但同时会把热送到手和衣物接触区域。热桥连接计算包络顶部到前铝壳；后盖用非金属材料；电池不被导热桥压住。导热桥实际芯片接触面未知，当前只体现路径，不是热阻仿真。金属壳、双天线和人体共存下需测Wi-Fi吞吐、GNSS C/N0/TTFF与定位成功率。

当前RF研究区没有发现与所列金属件的正体积相交；这仅说明占位几何没有侵入，不能证明远场电磁环境合格，尤其Zero板载天线位置与匹配尚未映射。

## 本机验证与未解决项

1. FreeCAD生成60个最终对象，全部几何有效；两两正体积相交阈值0.01mm³，修正后结果0。修正过盖板沉台、螺钉头沉孔、挂点/GNSS干涉、相机/麦克风包络和FPC搭接。
2. 原生FreeCAD GUI重新打开并保存了最终可见对象。STEP再导入检查另见`verification/reopen_check.json`。
3. Blender从相同STL按毫米→米导入，保存原生场景；为表面高光增加0.15mm显示倒角，未修改FreeCAD结构尺寸。镜头反光层与文字属于视觉标记，未作为新采购器件。
4. 从R0真实KiCad STEP导入了隐藏参考板，但**没有将它当作R2主板**。R2主板是新提议的68×70×1.6mm包络，尚无对应已布线PCB，不能声称完成R2跨软件PCB装配。
5. 电池到屏幕包络净距约0.7mm；电池按额外1mm厚度增长后到PCB净距约0.9mm。公差、电池导线、胶、翘曲和壳体形变仍会消耗这两个值。

尚未解决：各螺柱/支柱与壳体的最终承力连接；帽体固定及完整接缝；挂绳拉力与脱离机制；屏幕连接器真实高度；Zero原接口/天线几何；相机实际镜头轴和FPC完整弯折；GNSS真实天线与地板；麦克风子板/引线与声音通道频响；扬声器出声口/导管；USB和侧键密封；胶水具体牌号与相容性；装配顺序及公差链；热测试；真实ECAD。部分对象为合理空间占位，不能凭外观看似连接就认为可以装配。

质量：按材料密度计算的壳体、胶层和紧固等部分约74g；加电芯和电子估计整机155–190g，未包含可靠秤量。这一版明显偏重，应先当单件结构/功能研究样机。轻挂佩下一版需要缩计算平台、优化天线、改更薄金属结构并重新验证电池与续航；不以缩放当前模型实现。

最先实测：①真实负载+金属壳的温升与耗电；②胸前/衣物/手持下GNSS和Wi-Fi表现；③IMU活动误触发、衣物摩擦拾音及关机唤醒数据完整性。
