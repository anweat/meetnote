# 机械原型、装配和边界

本次以FreeCAD 1.1.3生成原生参数/布尔特征树，保存FCStd，并通过原生GUI补存可见性与颜色。主尺寸可从Parameters表修改；其它包络和孔位是可编辑Part尺寸/Placement参数。改变总体尺寸后必须重新检查孔位和装配，不是可以任意缩小而自动保证通过的优化模型。

## 坐标与装配

单位mm，原点在整机左下角底面，XY为长宽平面，Z向镜头外侧。外壳82×118×29；底壳与顶壳在16.0/16.2mm处分开，0.2mm分缝。底/顶壁1.8mm。4个M2壳体孔，塑料螺丝柱OD6、导孔1.7mm；载板支柱OD3.6。螺钉长度、牙型、扭矩、热熔螺母与抗跌落能力未选定，不能按模型直接采购紧固件。

载板70×70，四角倒角3mm，原点(6,42,11.6)。导入的是KiCad实际导出的板体STEP，包括板框和钻孔，非手画矩形替身。导出的板体厚度实测1.51mm，而名义成品厚度为1.6mm；铜、阻焊及最终叠层包络需要板厂确认，机械元件底面按1.6mm成品厚度定位，没有缩放STEP掩盖差异。

电池(11,49,2.2)，包络60×50×7.3；与名义载板下表面有2.1mm间隙，假设增厚1mm后尚余1.1mm。膨胀1mm不是电芯厂家保证，应取得容差/寿命证据。电池周围须绝缘、无尖锐焊脚，电芯上方禁止螺钉侵入。固定泡棉/可拆卸电池压带和线束尚未建模。

相机(44,73,14)，包络25×24×11.5，名义镜头最高点至顶壳内表面1.7mm。开窗、焦点轴位置按包络中心做原型假设，不能替代厂商机械图；镜头全AF行程、遮光筒、快门及玻璃装配公差需要进一步确定。Blender镜面圆片只是保留间隙内的展示表面，不是已选定光学零件。

麦克风/按钮/LED对应真实ECAD放置坐标建模近似实体。四路MIC底部声孔在KiCad标准封装中相对器件中心有偏移，外壳孔目前按中心规划，尚未建立偏移声道及声学密封。不能从“无实体相交”推断声学通道正确。

## 装配顺序建议

1. 安装绝缘电池固定件、外贴NTC及线束，检查极性，尚不接电。
2. 固定载板，再固定独立Zero和相机。后两者目前只有包络，尚缺已核准的完整螺钉/支架结构，是明确的装配未完成项。
3. 连接Zero专用CSI FPC及GPIO短线束。逐条预留弯曲半径、插拔抓手位置和应力释放；当前没有可用于钣金/注塑放行的线束扫掠模型。
4. 安装声学垫圈、导光柱、按钮、实体许可开关，再装散热路径。导热垫压缩率和接触压力未计算；按键约0.3mm初始间隙需结合实际开关行程复核。
5. 合壳前用实体量规检查镜头/电芯净空并做电气自检，最后装4个外壳螺钉。拆修必须先断开电池。

## 本机检查与剩余冲突

原始结果 `verification/mechanical_fit.json`；模型48个最终对象间两两计算共同实体体积，阈值0.01mm³。修正载板角部、接插件/相机、按键和导光柱布局后，已建模刚体实体穿插为0。此检查允许正确的面接触，并未包含未建模结构。

**保留2项RF空间冲突**：HeatSpreader和ThermalGapPad均进入保守的RFKeepout区域。RFKeepout目前覆盖整个Zero上端舱；这比实际天线区域大，但在核准天线位置与厂家净空前不删减禁区来换取“通过”。需要天线实际位置/近场和带壳OTA测试决定散热片形状、位置或换用带外置天线的计算模组。

仍未解决：SoC和相机最终固定、电池压带/泡棉、USB板/许可开关真实STEP、FPC和线束运动、MIC声道偏移和密封、螺丝工具可达性、注塑拔模/加强筋/缩水、跌落强度、按键行程、快门和镜头玻璃、全公差链。推荐原型SLA/CNC先做装配验证；FDM先按±0.3mm、机加工按±0.1mm作初步公差假设，必须由加工方确认。全尺寸缩小版未生成、未验证。

Blender从FreeCAD STL以固定0.001系数将mm转换成m，未分别缩放器件。正面、背面、剖视、示意手持四图均由同一模型渲染；剖视只对外壳增加切除面，内部器件位置保持不变。手型仅作尺寸参照，不能用于人体工学合格判定。
