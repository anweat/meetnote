# ECAD 实施约束与未完成项

工程为真实 KiCad 10 项目、主图+7个子页、四层70×70mm载板布局草案，含标准库 FPGA/MIC/阻容/按钮/LED/连接器和真实焊盘网络。**还没有完成可制造电路与布线。** POWER_ASSEMBLY、12M288_XO、HARD_INTERLOCK是明确的接口占位，无真实器件引脚映射；Camera与Wi-Fi块表示模组已有功能。不得将这些块视为完成的电路。

## 电源和时序

- 1S受保护电芯 → 电源路径充电 → 5V升压 → Zero；分离FPGA 1.2V、VPP 2.5V候选、3.3V I/O、PLL滤波及MIC供电。实际VPP允许范围、bank上电关系、复位时序需逐项按Lattice最新datasheet/参考板复核。R0的100Ω PLL串阻也是待计算值。
- 电源稳定后复位保持，SoC启动并验证bitstream签名，再通过SPI配置FPGA；配置完成CDONE高才释放捕获。共享SPI的MOSI/MISO配置方向必须核验；无NVCM量产烧录行为。
- 3.3V来源只允许单一驱动；J1的3.3V引脚当前与V3V3同名，但自有轨与Zero轨的角色**尚未设计**，禁止双源并联上电。J3是受控台架5V输入，不能与未完成电池路径同时接入。
- 物理开关硬件门控麦克风电源/时钟；关闭时FPGA输出应高阻避免MIC反向供电。摄像头供电隔离需Zero CSI供电路径或外置中介板实现，CSI差分线在未供电时也不得反向灌电。状态灯由实际已使能轨/门控输出驱动，最好具有故障检测；当前只是原理接口，**尚未实现隐私硬件保证**。
- 电池缺内置NTC，必须外贴并验证脱落/短路/开路故障；5V输入CC检测和限流、反向隔离、USB ESD、输入保险、电芯欠压保护、升压输出短路路径都未完成。

## 叠层、回流和高速约束

四层目标：L1信号/器件，L2完整GND，L3电源/低速信号，L4信号/局部GND。1.6mm成品厚，35µm铜是报价起点；未获板厂介质厚度、Dk与阻抗报告，不能声明50Ω/100Ω已经满足。KiCad板体STEP可能不含外层铜/阻焊，与总成品厚不同，具体实测包络记入报告。

- MIPI CSI走现成FPC直连Zero，相机路径不经过载板。CSI保护和中介板若新增，必须重新做100Ω差分、长度/对内偏差、连接器参考平面与眼图验证；严禁飞线MIPI。
- PDM 3.072MHz / MCLK12.288MHz / SPI12MHz仍有快速边沿；短线、同层参考连续GND；建议时钟源端22–47Ω阻尼作为调试位，数值实测。FPGA/MIC远离SW节点、电感、Wi-Fi天线；PDM DATA不跨分割平面。SPI预算长度<100mm，线束需地线交错，实际时间裕量用示波器验证。
- 电源输入/电感/开关管/输出电容高di/dt回路紧凑；热焊盘散热通孔按板厂能力，不能把芯片10A开关电流当走线负载。5V峰值1.2A及电芯>2A路径需按铜厚、温升及过孔能力设计，不能套用默认0.25mm线宽。
- USB连接器附近布置TVS和返回机壳/地的短路径；天线净空内不能放铜、金属螺钉、导热片、电池/FPC屏蔽层。现机械模型以整个SoC上端舱作保守RF禁区，散热片与其冲突未解决。
- Zero内部DDR/RF模块由原板负责，本载板不声称审查了其DDR设计或模块认证后的整机无线性能。

## 布局与机械接口

载板4角3mm倒角，M2孔中心(3,10)、(67,10)、(3,60)、(67,60)mm；全局位置为(6,42,11.6)mm。四枚底部声孔麦克风中心(4,4)、(66,4)、(4,66)、(66,66)mm。壳体麦孔当前按中心包络开孔，必须根据最终LLGA footprint实际声孔偏移复核并设计独立声学密封垫，避免四路声腔串音。

相机和GPIO排线需要弯曲半径/装配工序/应力释放；电池导线必须不跨螺丝、按键与镜头光路。热垫需要压缩范围而非刚体零间隙；镜头要检查全AF行程、遮挡/视场裁切、保护玻璃鬼影。所有连接器采用最大配对高度和拔插空间，不以裸座高度替代。

## 投板阻断清单

1. 所有UNVERIFIED块替换为厂商引脚级设计；审查电源输入/时序/反灌、硬件隐私门控、NTC、时钟与配置方式。
2. 逐针核查原厂规格 vs KiCad symbol vs footprint vs采购后缀，包括QFN裸焊盘、MIC声孔/选边、LED极性；复核去耦数量和距离。当前不是签审过的pin map。
3. 完成网络布线、地平面/天线禁布、线宽过孔规则和板厂叠层；DRC的未连接必须归零。当前无布线，Gerber只供检查导出链路。
4. 关闭ERC电源未驱动、引脚未连接和库不一致项；核对所有原理图与PCB差异，不能通过忽略检查伪造PASS。
5. 完成封装/真实STEP/公差和线束审查，再由另一名硬件工程师复核及台架上电。
