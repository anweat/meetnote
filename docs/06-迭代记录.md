## R0 · 工程概念原型

**目录**：[`iterations/MeetNote-R0/`](../iterations/MeetNote-R0/)｜约 15 MB

| 项 | 结果 |
|---|---|
| 产品形态 | 桌面 4–8 人会议记录器，82×118×29 mm |
| 电子 | KiCad 四层 70×70 mm 载板草案；主图 + 7 子页、36 个原理图引用、35 个 PCB 封装、80 个导出网络 |
| 机械 | FreeCAD 48 个最终对象；外壳 + 载板 + 电池 + 相机 + MIC/按键/LED 包络 |
| 软件 | OpenAPI 草案；`pipeline.py` 参考实现；12/12 本机测试 |
| 验证 | ERC 3 errors + 7 warnings；DRC 4 violations + 93 unconnected；实体相交 0（阈值 0.01 mm³）；RF 冲突 2 项 |
| 关键估算 | 2.45 W、2.39 h、调试 2.142 GB/场、20 GB 数据区约 9 场 |
| 工具 | KiCad 10.0.6 / FreeCAD 1.1.3 / Blender 5.2.2 LTS |

**为什么停在 BLOCKED**：电源总成、12.288 MHz 时钟、硬件许可门控是接口占位；PCB 未布线；无 bitstream/固件/服务端；35 °C 触温目标不成立；电芯脉冲能力无证据。

**留下的关键产物**：[验收记录](../iterations/MeetNote-R0/verification/验收记录.md)、[ECAD 约束](../iterations/MeetNote-R0/docs/03_ECAD_constraints.md)、[软件协议](../iterations/MeetNote-R0/docs/04_软件与数据协议.md)、[机械约束](../iterations/MeetNote-R0/docs/05_机械装配与制造约束.md)、[8 页原理图 PDF](../iterations/MeetNote-R0/electronics/schematic.pdf)。

## R1 · 可挂佩 AI 助手设计细化

**目录**：[`iterations/MeetNote-R1-design/`](../iterations/MeetNote-R1-design/)｜约 216 KB

**变化**：用户确认定位从「会议记录器」调整为「圆润、可挂佩的 AI 助手」，会议记录保留为核心模式。R0 原文件完整保留，R1 没有继承 R0 的 CAD 检查结论，也没有新增可投板文件。

**产出**：

- 产品与工程基线：场景、范围、实体操作、音频输出、接口、热设计、尺寸、成本、验证门槛。
- 离线交互原型 `design-review.html`：切换「记住 / 看一下 / 回顾 / 会议」模式，切换两档尺寸，调整电池与负载重算续航；键盘可操作、无网络请求。
- 成本工作表：100 台 500 元/台分配。
- `design_parameters.json` + `check_design.py`：所有研究假设的机器可读版本与重算脚本。

**本机验证**：

- 预算分配总额 500 元；R1 会议续航 **2.254 h**；屏幕 10 fps 负载 10.752 Mbit/s。
- 68×90×26 mm 热筛查：平均壳温约 **62.8 °C**；54×72×22 mm 约 **77.7 °C**；均 FAIL，且模型未校准。
- 浏览器加载、键盘激活断网状态与会议模式、尺寸切换与 Python 公式一致；未做全分辨率回归。
- 不含新 ERC/DRC、FreeCAD 干涉、Blender 工程渲染或供应商报价。

**放行**：BLOCKED；允许继续产品研究、台架验证与器件筛选。

## R3 Lite · 200–300 元路线

**目录**：[`iterations/MeetNote-Lite-R3/`](../iterations/MeetNote-Lite-R3/)｜约 76 KB

**定位**：独立低成本分支，R2 金属版源文件与评审页保持原状。

| 项 | 结果 |
|---|---|
| 架构 | Luckfox Pico Mini A（RV1103、64 MB）+ Tang Nano 1K + SC3336 + 双麦 + USB Wi-Fi |
| 预算 | 目标 296 元，区间 245–403 元；15% 预备金后 340.4 元 |
| 结论 | 接近 300 元的自装实验机有条件成立；200 元完整实现没有可信采购闭环 |
| 增配 | 电池 40、蓝牙 18、加速度计 15、GNSS 85、小屏 40、9K FPGA 45 |
| 未做 | RTL 综合、目标板程序、ERC/DRC、CAD 干涉、射频/声学/热/电池测试；无新 KiCad/FreeCAD 文件 |

**关键约束**：Mini 仅 17 GPIO；1K 的 9 KiB RAM 只够约 28 ms 原始 PCM 缓冲；Wi-Fi 芯片/驱动仍是阻断项；TF 系统卡不可热插拔。

## 四轮共同的方法

1. **先写验收条件，再给结论**：每个指标都有通过条件，避免“看起来可以”。
2. **保留原始证据**：ERC/DRC 日志、JSON、截图、退出码原样保存；不删失败记录。
3. **区分估算与本机验证**：E0/E1/E2 标注贯穿所有文档。
4. **不隐藏冲突**：RF 禁区冲突、热目标 FAIL、93 条未连接都保留在交付物里。
5. **每轮独立可读**：新轮次不覆盖旧文件，旧结论仍可追溯。
