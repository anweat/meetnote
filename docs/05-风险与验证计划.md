## 4. 下一步实测（按依赖顺序）

### 第一优先：供电 / 热 / 佩戴台架

真实电芯在低电量、拍照 + 上传峰值、35 °C 环境连续 2 h：

- 记录各轨电压、峰值电流、效率、壳体热点、电池温度。
- 验证低电量封存与充电限制。
- 通过条件：无欠压复位、2 h 完成、既定触温、电芯规格内运行。
- 未通过就改平台或尺寸，不进入下一阶段。

### 第二优先：音频连续性与物理停止

4–8 人真实会议，上传/拍照/SD 写入并行：

- 注入 200 ms 主机服务停顿，对照采样计数测丢样、串音、噪声、ASR 可用度。
- 冻结软件时拨实体开关，硬件采集必须停止、指示灯准确。
- 同时决定 FPGA 是否值得保留（与 ADC + DMA 对照功耗与可靠性）。

### 第三优先：带壳图像与无线

装真实 FPC、金属散热件和电池：

- 对比裸板/带壳 Wi-Fi 有效吞吐、BLE 共存、2 h 断网续传。
- 0.5–3 m 拍白板/投影，核查原图/裁切文字可读性、AF、频闪、手抖。
- 通过后再缩小外形。

### 第四优先：成本与供应链锁定

- 同一版 BOM + 坐标文件正式报价；确认汇率、税费、库存、交期。
- 关键器件（Wi-Fi、相机、麦克风、电芯、连接器）锁定型号与替代料。

### 第五优先：用户价值验证

- 等重模型佩戴 ≥30 min；10 个任务对比手机；短回答 vs 长文本偏好。

## 6. 验证原则

1. **不删禁区换通过**：RF 禁区、ERC/DRC 规则不为了“全绿”而放宽；保留失败记录。
2. **退出码 0 不等于通过**：工具完成检查/导出只说明流程跑通，结论要看实际违规项。
3. **不缩放模型凑尺寸**：STEP 与名义厚度差异原样记录；不能用 Blender 缩放掩盖干涉。
4. **不把预算当实测**：所有 E0 数字在文档中显式标注“估算”。
5. **失败要可追溯**：日志、JSON、截图原样保存，便于下一轮对比。

## 7. 当前明确的“未完成”

- 电气：电源总成、时钟、硬件许可门控、充电/5V/低压轨/CC/ESD/NTC/反向供电、真实 MPN 逐针校验。
- PCB：93 条连接未布线、4 个 MIC 孔距违规、GND 平面/叠层/阻抗/EMI/热过孔未完成。
- FPGA/固件：无可综合时序收敛的 PDM 抽取、SPI/时钟域交叉、bitstream、Linux 驱动。
- 软件：VAD/降噪/关键词、相机驱动、服务端部署、安全密钥存储、A/B 更新。
- 结构：真实器件 STEP、线束/FPC 弯折、密封、承力连接、公差链、跌落、挂绳。
- 热/无线：实测温升、电芯脉冲、带壳 OTA。
- 成本：正式报价。
